# 在飞书网页查看演示表

1. **打开演示表。** 在工作台确认顶部显示“飞书多维表格”，点击数据表标题旁的“打开飞书表格”。使用有权访问这张表的飞书账号登录。在表格视图找到刚才写入的论文，核对标题、论文链接和方法概述。
2. **查看字段类型。** 双击“论文链接”的列名，在字段面板里读出当前类型。关闭面板，再双击“方法概述”查看它的类型。直接关闭面板即可结束查看。[飞书帮助中心《快速上手多维表格》](https://www.feishu.cn/hc/zh-CN/articles/697278684206-快速上手多维表格)
3. **查看整份表的协作者。** 点击右上角“分享”，再点击“邀请协作者”右侧的头像区域，打开“管理协作者”。成员旁会显示当前的“可阅读”“可编辑”或“可管理”。录屏可裁去姓名和头像，只展示权限标签。若账号只能看到自己的权限，可将鼠标悬停在“分享”上展示实际可见的信息。[飞书帮助中心《快速上手云文档权限》](https://www.feishu.cn/hc/zh-CN/articles/360025093793-快速上手云文档权限)
4. **查看角色的行列权限。** 点击数据表右上角“高级权限”。已启用时，选择一个已有角色，在“数据权限”中找到当前数据表，查看该角色能阅读或编辑哪些记录、哪些字段。若页面提示“开启高级权限”，录下此状态后关闭即可。若账号看不到入口，可以说明当前账号的可见范围。工作台本地演示库另备有“论文审阅人”角色，可用于演示角色权限的调整。[飞书帮助中心《多维表格高级权限角色介绍》](https://www.feishu.cn/hc/zh-CN/articles/539823920318-多维表格高级权限角色介绍)

飞书模式下若没有“打开飞书表格”入口，在演示表页面选中目标数据表，复制浏览器地址。用已登录的 CLI 身份运行以下命令，粘贴链接后重新启动工作台。绑定信息保存在本机。

```powershell
python tools/feishu_setup.py --mode cli
python app.py --mode feishu-cli --agent codex --port 18970 --open
```
